# 👟 SyntaxWear

SyntaxWear é uma aplicação de e-commerce de calçados desenvolvida com tecnologias web modernas, focada em uma experiência de compra simples, rápida e responsiva.

## 🚀 Tecnologias Utilizadas

- **React 19**
- **TypeScript**
- **Vite**
- **TanStack Router**
- **Tailwind CSS v4**
- **React Hook Form**
- **Zod**
- **React Icons**
- **Context API**

## ✨ Funcionalidades

- Catálogo de produtos
- Filtro por categorias
- Página de detalhes do produto
- Carrinho de compras
- Simulador de frete por CEP
- Login e cadastro
- Páginas institucionais (Sobre e Lojas)

## ▶️ Como Executar

### Pré-requisitos

- Node.js 18 ou superior
- npm, yarn, pnpm ou bun

### Instalação

```bash
git clone <url-do-repositorio>

cd syntax-wear-app

npm install

npm run dev
